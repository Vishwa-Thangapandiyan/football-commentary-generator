# SETUP: running this after cloning

## TL;DR

Both commentary models, the comparison, the grounding test and all metrics work
immediately after cloning. The **video** demos do not: they need SoccerNet
broadcast video, which is NDA-covered and cannot be redistributed. Download it
with your own SoccerNet NDA password.

```bash
git clone --recurse-submodules https://github.com/Vishwa-Thangapandiyan/football-commentary-generator.git
cd football-commentary-generator
pip install -r requirements.txt
python compare.py            # BDH vs Transformer, side by side
```

Requirements: Python ≥ 3.11, PyTorch ≥ 2.9 (CUDA optional; CPU works, slower),
Java (only for METEOR in `metrics.py`).

## What ships in the repo

| Included | Why |
|---|---|
| `checkpoints/transformer_v3_best.pt`, `checkpoints/bdh_v3_best.pt` | the two final models; vocabulary and target mask are stored inside |
| `checkpoints/full_best.pt` | original V1 Transformer, used by the demos |
| `data/processed_v3.json`, `data/processed_v3_noevt.json`, `data/vocab_v3*.json` | final V3 data (+ ablation) and vocabularies |
| `data/processed.json`, `data/processed_v2.json`, `data/vocab*.json` | V1 / V2 data (history) |
| `data/splits.json`, `data/v3_window.json` | official game-level splits; the V3 alignment window |
| `outputs/seeds/` | every generated test sentence of every seed run, plus training histories |
| `outputs/metrics_v3.json` | the metric table in RESULTS.md |
| `third_party/bdh` | official BDH code, as a git submodule at commit `2b0d7a4` |

## What does NOT ship, and why

| Excluded | Reason | How to get it |
|---|---|---|
| `data/caption-2024/` | labels are public, but the folder also holds **NDA video + features** | `python download_and_parse.py download`, `python build_v3.py download` (public labels, no NDA) |
| `*.mkv`, `*.mp4`, `outputs/web/` | **NDA-covered broadcast video** | `python download_video.py` with your own NDA password |
| `*.npy` (ResNET features) | derived from the video | see below |
| `*.jpg`, `*.png` | frames of the NDA video | regenerated by the video scripts |
| `models/spivak/` (75 MB) | third-party action-spotting model (CC-BY-4.0), large | curl commands below |
| `checkpoints/v2_best.pt`, per-seed checkpoints | only the final checkpoints are needed | retrain (`train.py` / `train_bdh.py` / `colab_seeds.py`) |
| `yolov8n.pt` | auto-downloads on first use | nothing to do |

## Works immediately after clone (no NDA, no downloads)

```bash
python compare.py                       # both models, same test events, side by side
python generate.py --ckpt checkpoints/bdh_v3_best.pt --data data/processed_v3.json --split test --n 8
python test_grounding.py --ckpt checkpoints/transformer_v3_best.pt --data data/processed_v3.json --n 200
python metrics.py "outputs/seeds/eval_*_v3_*.json" --train-data data/processed_v3.json
python demo_json.py                     # http://127.0.0.1:8010
python demo_live.py                     # http://127.0.0.1:8000
python model.py                         # Transformer self-test
python vocab.py test --data data/processed_v3.json --vocab data/vocab_v3.json
```

## Training on a cloud GPU (optional)

Training both models with 3 seeds takes about an hour on a Colab A100. With the
[Colab CLI](https://github.com/googlecolab/google-colab-cli) installed and signed in
(`colab --auth oauth2 new --gpu A100`):

```bash
# upload the code and data/processed_v3.json, data/vocab_v3.json to /content/proj, then
colab exec -s <session> --timeout 9000 --env DSET=v3 -f colab_seeds.py
python colab_watch.py -s <session> --last eval_tf_v3_a100_s2
```

`colab_watch.py` downloads every result as soon as its job finishes (Colab can
reclaim a VM without warning) and stops the session at the end so it does not bill
while idle. On a Tesla T4, pass `--env GPU=t4 --env BDH_AMP=fp16 --env TF_AMP=fp16`.

## Needs the SoccerNet NDA (video demos)

`demo_app.py`, `demo_final.py`, `demo_render.py` and `spot_to_commentary.py` need
media we cannot ship. `demo_final.py` also needs `checkpoints/v2_best.pt`, which is
not included.

1. Get an NDA password from <https://www.soccer-net.org/data>.
2. Download the video (first half of the demo match), keeping the password out of
   your shell history:
   ```bash
   read -rs SOCCERNET_PASSWORD && export SOCCERNET_PASSWORD
   python download_video.py
   unset SOCCERNET_PASSWORD
   ```
3. Download the ResNET features (public, no NDA needed):
   ```bash
   g="england_epl/2014-2015/2015-05-17 - 18-00 Manchester United 1 - 1 Arsenal"
   curl -sL -u "9eRjic29XTk0gS9:SoccerNet" -o "data/caption-2024/$g/1_ResNET_TF2.npy" \
     "https://exrcsdrive.kaust.edu.sa/public.php/webdav/${g// /%20}/1_ResNET_TF2.npy"
   ```
4. Fetch the spivak action-spotting model (CC-BY-4.0):
   ```bash
   B="https://huggingface.co/yahoo-inc/spivak-action-spotting-soccernet/resolve/main"
   M="models/spotting_test_resnet_normalized_confidence_zoo_lr1e-3_dwd2e-4_sr0.5_mu2.0/best_model"
   mkdir -p "models/spivak/$M/variables" models/spivak/models
   for f in saved_model.pb keras_metadata.pb variables/variables.index variables/variables.data-00000-of-00001; do
     curl -sL -o "models/spivak/$M/$f" "$B/$M/$f"; done
   curl -sL -o models/spivak/models/resnet_normalizer.pkl "$B/models/resnet_normalizer.pkl"
   ```
   Requires TensorFlow (`pip install tensorflow`).
5. `demo_app.py` remuxes the `.mkv` to browser-playable `.mp4` automatically (needs
   `ffmpeg` on PATH).

## Things that will silently break it

1. **Do not regenerate `data/vocab.json`.** `checkpoints/full_best.pt` predates the
   target-vocabulary mask, so `generate.load_model` recovers the mask from
   `data/vocab.json`, guarded by an exact token-order check. A rebuilt vocab fails the
   check and decoding continues **without the team-name mask**, printing only a
   warning. The V3 checkpoints store their mask internally and are not affected.
2. **Always pass `--tag` to `train.py`.** Its default tag writes
   `checkpoints/full_best.pt`, overwriting the shipped V1 model. `train.py overfit`
   likewise overwrites `checkpoints/overfit.pt`.
